# Mission Reflection

Completing Mission 3 helped me understand the differences and similarities between AWS, Microsoft Azure, and Google Cloud Platform. Among the three platforms, Google Cloud Platform impressed me the most because of its strong capabilities in Artificial Intelligence, Machine Learning, and Kubernetes. However, I also learned that AWS and Azure have their own strengths and can be more suitable depending on the needs of an organization.

AWS, Azure, and GCP have many similarities because they all provide essential cloud services such as computing, storage, networking, databases, identity management, and scalable infrastructure. They also allow organizations to access resources through cloud management consoles and deploy applications without relying entirely on physical infrastructure.

Business requirements play an important role in selecting a cloud platform. Factors such as budget, existing technologies, scalability, security, performance, and specific application requirements should be considered before choosing a provider. For example, Azure is a strong choice for an organization that already uses Microsoft technologies, while GCP can be suitable for AI and Machine Learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The decision should be based on the client's specific problems, goals, available resources, and future plans. Comparing different services also helped me understand how cloud technologies can solve different business requirements.

My GitHub Cloud Computing Portfolio improved after completing this mission because it now contains organized documentation about multiple cloud platforms, service comparisons, client recommendations, and Linux investigation results. This activity also helped me practice using Markdown and organizing technical information in a professional way. Overall, Mission 3 improved my understanding of cloud platforms and helped me think more like a Cloud Solutions Consultant.
