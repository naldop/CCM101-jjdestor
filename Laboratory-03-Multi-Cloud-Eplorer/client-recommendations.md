# Client Recommendations

## Checkpoint 4 – Cloud Platform Recommendation Challenge

### Client A – Startup Company

**Recommended Platform: AWS**

AWS is a suitable choice for a startup because it provides scalable cloud resources that can support a company as it grows. Its wide range of services allows the startup to build and deploy a mobile application without needing to manage physical infrastructure. The company can start with the resources it needs and scale them as demand increases.

**Recommended Services:**

* Amazon EC2 – Application computing
* Amazon S3 – Object and file storage
* Amazon RDS – Managed relational database

### Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management more convenient. The university can also use Azure to support hybrid cloud environments.

**Recommended Services:**

* Azure Virtual Machines – Windows Server workloads
* Microsoft Entra ID – Identity and access management
* Azure Blob Storage – Cloud storage

### Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a strong choice for an AI research company because it provides services designed for Artificial Intelligence and Machine Learning workloads. Its cloud infrastructure can provide scalable computing resources for demanding research applications. GCP also provides services that support data processing and machine learning development.

**Recommended Services:**

* Compute Engine – High-performance computing
* Vertex AI – AI and Machine Learning development
* Cloud Storage – Data and research storage

### Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is a suitable choice for a global e-commerce company because it provides scalable and highly available cloud infrastructure. The company can deploy applications across multiple geographic locations and scale resources according to customer demand. This makes AWS appropriate for a large online shopping platform serving customers worldwide.

**Recommended Services:**

* Amazon EC2 – Application servers
* Amazon S3 – Object storage
* Amazon Auto Scaling – Automatic resource scaling

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform | Justification                                                                                   |
| ----------------------- | -------------------- | ----------------------------------------------------------------------------------------------- |
| Startup Company         | AWS                  | Scalable services and a broad range of cloud resources can support startup growth.              |
| Enterprise Organization | AWS                  | Provides extensive services for enterprise workloads, security, and scalability.                |
| Microsoft Environment   | Microsoft Azure      | Strong integration with Windows Server, Microsoft 365, and Microsoft identity services.         |
| AI / Machine Learning   | GCP                  | Strong focus on Artificial Intelligence and Machine Learning services.                          |
| Kubernetes Deployment   | GCP                  | Google Cloud provides strong Kubernetes and container support through Google Kubernetes Engine. |
| Global Web Application  | AWS                  | Global infrastructure and scalable services can support applications serving users worldwide.   |

## Summary

The best cloud provider depends on the specific requirements of each organization. AWS is a strong general-purpose choice, Azure is particularly suitable for organizations using Microsoft technologies, and GCP is a strong option for Artificial Intelligence, Machine Learning, and Kubernetes workloads.
