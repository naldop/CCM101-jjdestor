# Laboratory 03 – Multi-Cloud Explorer

## Mission 3: Become a Multi-Cloud Explorer

This laboratory activity explores three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity focuses on researching their services, comparing their capabilities, and determining which cloud platform is most appropriate for different business requirements.

## Mission Objectives

* Explore the major public cloud platforms.
* Identify the core services offered by AWS, Microsoft Azure, and GCP.
* Compare cloud services across different providers.
* Analyze business requirements and recommend appropriate cloud solutions.
* Create professional technical documentation using Markdown.
* Continue developing a well-organized GitHub Cloud Computing Portfolio.

## Cloud Platforms

### Amazon Web Services (AWS)

AWS is one of the major public cloud platforms used by organizations for computing, storage, networking, databases, and other cloud services.

**Core Services:**

* Amazon EC2 – Compute
* Amazon S3 – Object Storage
* Amazon VPC – Networking
* AWS IAM – Identity and Access Management

**Advantages:**

* Broad range of cloud services
* Global infrastructure
* Flexible and scalable resources

**Typical Enterprise Use Cases:**
AWS can be used for web applications, enterprise systems, data storage, backup, and scalable cloud infrastructure.

### Microsoft Azure

Microsoft Azure is a public cloud platform that provides computing, storage, networking, database, security, and other cloud services.

**Core Services:**

* Azure Virtual Machines – Compute
* Azure Blob Storage – Object Storage
* Azure Virtual Network – Networking
* Microsoft Entra ID – Identity

**Advantages:**

* Strong integration with Microsoft technologies
* Enterprise-focused cloud services
* Global infrastructure

**Typical Enterprise Use Cases:**
Azure can be used for Windows-based workloads, Microsoft 365 environments, enterprise applications, databases, and hybrid cloud infrastructure.

### Google Cloud Platform (GCP)

Google Cloud Platform provides cloud computing, storage, networking, databases, artificial intelligence, machine learning, and Kubernetes services.

**Core Services:**

* Compute Engine – Compute
* Cloud Storage – Object Storage
* Virtual Private Cloud – Networking
* Google Kubernetes Engine – Kubernetes

**Advantages:**

* Strong Artificial Intelligence and Machine Learning capabilities
* Strong Kubernetes and container support
* Global cloud infrastructure

**Typical Enterprise Use Cases:**
GCP can be used for AI and machine learning applications, data analytics, containerized applications, web applications, and scalable cloud workloads.
