## Mission Reflection



Object storage is better for storing millions of photos because it can store a very large number of files and can easily grow as more photos are added. Each photo is stored separately with its own information and ID. Photos can also be accessed easily through the internet, which is useful for websites and mobile apps.



Docker made the setup easier because I only needed one command to download and start MinIO. The command also set the ports and login information. I did not need to install MinIO and its other requirements manually. When there was a problem, I could remove the container and run it again quickly.



A bucket is a container used to store files or objects in object storage. It is similar to a main folder where files are kept. In this lab, I created a bucket called client-photos and used it to store the file I uploaded.



Large companies protect their data by keeping multiple copies in different servers or locations. Some systems also use special methods that can rebuild lost data if a server fails. They may also use backups and versioning to protect files from being accidentally deleted.



My confidence in using the Linux command line has improved. I can now run Docker commands, check containers using docker ps, and use commands like git and nano. Fixing the Docker errors taught me to read error messages carefully and find solutions. I still need more practice with longer commands and Git conflicts.
