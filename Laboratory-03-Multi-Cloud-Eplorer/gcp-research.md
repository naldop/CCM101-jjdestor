# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides services for computing, storage, networking, databases, Artificial Intelligence, Machine Learning, and application development. It allows organizations to build, deploy, and manage applications using Google's cloud infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of **regions and zones** located in different geographic areas. Regions contain multiple zones that provide isolated locations for deploying resources. This infrastructure helps organizations build applications with high availability, scalability, and reliability.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to create, configure, monitor, and manage Google Cloud resources. Users can manage virtual machines, storage, networks, databases, Kubernetes clusters, and other cloud services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides scalable virtual machines that allow organizations to run applications and workloads on Google's infrastructure.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store files, backups, media, application data, and other types of unstructured data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities for connecting and managing cloud resources in a controlled virtual network environment.

### 4. Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. **Strong AI and Machine Learning Capabilities** – GCP provides services and infrastructure that support Artificial Intelligence and Machine Learning workloads.
2. **Kubernetes Support** – GCP provides strong support for containerized applications through Google Kubernetes Engine.
3. **Global Infrastructure** – Google Cloud provides infrastructure distributed across different regions and zones around the world.

## Typical Enterprise Use Cases

Google Cloud is commonly used by enterprises for:

* Artificial Intelligence and Machine Learning applications
* Data analytics and processing
* Containerized applications
* Kubernetes deployments
* Web and mobile applications
* Large-scale data storage
* Scalable cloud workloads
