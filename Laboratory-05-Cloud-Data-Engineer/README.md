

# Laboratory 05: Cloud Data Engineer

## Mission Overview

In this mission, I worked as a cloud data engineer for a client who needs a place to store images uploaded by users. I learned about the three main types of cloud storage and compared them. I also set up a MinIO object storage server using Docker. After that, I used the MinIO web console to create a bucket and upload a file.

## Objectives

* Learn about block, file, and object storage and explain why object storage is good for user-uploaded images.
* Set up a MinIO server using Docker in a KillerCoda Ubuntu Playground.
* Open the MinIO web console, create a bucket, and upload a file.
* Document the steps and explain what I learned from the activity.

## Tools Used

* Docker
* MinIO (S3-compatible object storage)
* KillerCoda Ubuntu Playground
* Linux command line
* Git and GitHub
* Markdown

## Skills Learned

* Understanding the differences between block, file, and object storage.
* Setting up a service using Docker commands, ports, and environment variables.
* Fixing common Docker errors, such as image download problems and container name conflicts.
* Creating buckets and uploading files using the MinIO web console.
* Writing clear technical documentation using Markdown.
