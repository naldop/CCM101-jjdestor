# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, and application development. It allows organizations to deploy and manage applications and IT infrastructure through Microsoft's cloud platform.

## Global Infrastructure

Azure operates a global infrastructure consisting of **regions, availability zones, and data centers**. Azure regions are geographic locations that contain one or more data centers. Availability Zones provide physically separate locations within supported regions to improve application availability and resiliency.

## Cloud Management Console

The **Azure Portal** is a web-based management interface used to create, configure, monitor, and manage Azure resources. Through the portal, users can manage virtual machines, storage, networks, databases, security, and other Azure services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers that allow organizations to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and other files.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources and allows organizations to control network connectivity and communication between cloud resources.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, identities, authentication, and access to resources.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft products and technologies such as Windows Server and Microsoft 365.
2. **Enterprise Support** – Azure provides services designed for enterprise applications, security, and hybrid environments.
3. **Scalability** – Azure resources can be scaled according to application and business requirements.

## Typical Enterprise Use Cases

Azure is commonly used by organizations for:

* Hosting Windows-based applications
* Running virtual machines and enterprise workloads
* Integrating cloud services with Microsoft 365
* Hybrid cloud environments
* Database hosting
* Enterprise application development
* Data storage and backup
